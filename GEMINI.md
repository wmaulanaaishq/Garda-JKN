# Aturan Git & Manajemen Repositori
- **Jangan pernah melakukan `git push` secara otomatis** setelah melakukan `git commit`, kecuali pengguna secara eksplisit menginstruksikan untuk mem-push perubahan (misalnya dengan perintah "push ke github").
- Semua perubahan kode atau dokumen yang sudah final hanya boleh di-commit secara lokal (contoh: `git commit -m "..."`) untuk menjaga kebersihan riwayat remote.
